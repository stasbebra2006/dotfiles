# 💤 LazyVim

The separate LazyVim profile, launched with `lazy-nvim`.
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

Configuration lives in `~/.config/lazy-nvim`; data, state, and caches use the
matching `lazy-nvim` roots. The launcher retains the system/Homebrew Neovim core.
Ordinary `nvim` and VS Code use the separate native base in `~/.config/nvim`.

See `docs/nvim/README.md` in the chezmoi repository for profile ownership and
migration details.
